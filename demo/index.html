          Experimental engines. R0 supports a finite JavaScript subset; Boa uses a reviewed WASM
          checkpoint runtime when configured. Signed packages expire within their 10-minute window.
          Browser code and expiry checks can be inspected and patched.
        

        

          Supported JavaScript
          

            Export a function named main. R0 requires a synchronous function. In R0,
            use primitive values, local functions, variables, arithmetic, comparisons, conditionals,
            and bounded loops. The compiler rejects unsupported syntax. This demo supplies no host
            imports.
          

          

            R0 excludes objects, arrays in source, classes, DOM APIs, promises, exceptions,
            closures, and general JavaScript modules. The arguments field is a JSON array used to
            call main.
          

          

            Boa compiles a single module named /main.mjs. It accepts no ambient imports
            or host APIs. Both modes use primitive call arguments and return values. Boa has a
            200,000-instruction context budget, a fixed Date clock at 0 ms, and a UTC timezone. It
            provides broader language features and built-ins; full ECMAScript conformance is not
            established.
          

        

        

          Dialect and expiry
          

            Compile to see the artifact format, dialect, instruction count, and expiry.
          

          

          

            JoVault is a separate compiler and runtime research project under JoVM. This output does
            not use the main JoVM protocol. R0 requires a matching runtime and dialect. Boa requires
            its pinned WASM runtime and reviewed audit. A copied browser runtime cannot enforce
            secrecy or hard revocation.
          

        

        

          Execution limits
          

            Native execution runs in your browser. Boa compilation uses an isolated server worker
            with a 5-second deadline; only one Boa compilation runs at a time. Each browser run
            starts a fresh worker and stops after 2 seconds. Results must be primitive values and
            are limited to 8,192 characters. Elapsed times include worker startup and are single-run
            observations.
          

          

            Native and R0 worker policy blocks fetch, XHR, WebSocket, and nested workers. The
            optional Boa worker can fetch pinned assets from this demo origin and compile WASM using
            its explicit wasm-unsafe-eval policy. All workers block nested workers.
            Module imports are limited to this demo origin and blob URLs. Use code you choose to
            run. Compilation stays on this loopback server.
